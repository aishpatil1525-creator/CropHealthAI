# 🌱 Smart AI Crop Health — Brinjal Edition 🍆

**A frontend-only crop health monitoring website designed for brinjal (eggplant) plants.**

## 📌 About the Project

Smart AI Crop Health is a web-based project that helps users explore common brinjal crop diseases, upload leaf images, view sample analysis results, and maintain scan history.

The website is developed using HTML, CSS, and JavaScript. It features a responsive dashboard, a crop-care assistant, profile management, multiple interface languages, and light/dark themes.

> **Note:** This version is a frontend prototype. It does not currently use a trained AI model to identify diseases from uploaded images.

## 🎯 Problem Statement

Brinjal plants can be affected by different diseases that impact plant growth and crop production. Identifying symptoms early can help farmers take appropriate action.

This project provides a simple digital interface for exploring brinjal health information and demonstrating an image-analysis workflow.

## ✨ Features

- 🏠 **Dashboard:** View scan statistics and recent activity.
- 🍆 **Brinjal Image Scanner:** Upload and preview leaf images.
- 🔬 **Sample Analysis:** Display example crop-health results.
- 🦠 **Disease Guide:** Explore common brinjal health problems.
- 🕘 **Scan History:** Save and view previous demo results.
- 💬 **Crop Assistant:** Get preset responses to general crop-care questions.
- 👤 **Profile Management:** Create a local demo account and update profile details.
- 🌐 **Language Options:** English, Hindi, and Marathi interface labels.
- 🌙 **Dark Mode:** Switch between light and dark themes.
- 📱 **Responsive Design:** Adapt the layout for desktop, tablet, and mobile screens.

## 🦠 Brinjal Health Categories

The educational guide includes:

1. Healthy plant reference
2. Bacterial wilt
3. Leaf spot
4. Phomopsis blight and fruit rot

Symptoms may overlap between different diseases and other plant stresses. The guide is for educational purposes and does not replace expert diagnosis.
